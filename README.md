# Noma Weddings

Site de portfólio + proposta da Noma Weddings. Página única em HTML/CSS (`index.html`), sem dependências. Logo e fotos estão embutidas no próprio arquivo.

Publicado com GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Editar o conteúdo

- **Filmes do portfólio:** seção `id="portfolio"`.
- **Pacotes e valores:** seção `id="proposta"`.
- **Cores:** variáveis no topo do CSS (`--vinho`, `--gelo`, `--ouro`, `--preto`).
